# Přenositelnost na 14 krajů

Následující jsou zadání pro další zkoušky, nikoli výsledky prověření konkrétních nemovitostí. Vybrat vždy jednoznačnou skutečnou nemovitost a vhodné oprávněné podklady; nevymýšlet parcelní identifikátory.

| Kraj | Typ úlohy |
|---|---|
| Praha | Bytová jednotka, prohlášení vlastníka, podíl na společných částech |
| Středočeský | Pozemek v rozvojové ploše, účinný plán a konkrétní stavební záměr |
| Jihočeský | Dům u vodního toku, různé povodňové podklady |
| Plzeňský | Venkovský statek, více souvisejících parcel a přístup |
| Karlovarský | Objekt v územní památkové ochraně |
| Ústecký | Areál s těžební historií, geologie a staré zátěže |
| Liberecký | Svažitý pozemek, geometrie versus orientační terénní podklad |
| Královéhradecký | Dům s neúplným LV a starší listinou |
| Pardubický | Zemědělský pozemek a společná zařízení pozemkových úprav |
| Vysočina | Vlastnický podíl versus evidovaný uživatel LPIS |
| Jihomoravský | Byt, terasa a sklep; režim užívání versus vlastnictví |
| Olomoucký | Pozemek s omezeným přístupem a navazujícími parcelami |
| Zlínský | Dům a plán přístavby, místní územní dokumentace |
| Moravskoslezský | Bývalý průmyslový areál, poddolování a kontaminace |

Pro každý scénář kontrolovat i negativní větev: chybný katastr, prázdný zdroj, odmítnutý přístup, chybějící dokument a neurčitý čas. Pouhé vrácení HTTP 200 není ověření obsahu.
